16 modules, one install

Popups, reviews, wishlist, bundles, cart upsells, cookie consent, post-purchase upsells, reports, advanced analytics, OTP/COD, a page builder, and product sourcing — toggled independently.

Storefront stays lean

A single theme app-embed boots a lazy loader. Only the JavaScript for the modules a merchant enables ships to the storefront.

Real platform underneath

Remix + Prisma + Supabase PostgreSQL, Shopify OAuth, GDPR compliance webhooks, App Subscriptions billing, entitlement-gated APIs, and 72 Liquid blocks.
